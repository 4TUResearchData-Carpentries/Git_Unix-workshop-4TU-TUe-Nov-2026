Why Git, or any other version control software?

A group coding project

In research and software projects, many people may work on the same files: scripts, data notes, reports, documentation.

Each of them have the same copy of the code base of the project, but they are working on different parts of it.

A group coding project : Challenges

  • How to merge all these different copies together and maintain a final copy of the project?
  • What changed between two versions of the same analysis?
  • Which merge did work and which one did not?
  • Who changed what and when?

What is Git?

  • It was created in 2005 by Linux Torvalds , the same creator of Linux OS.
  • Git is free, open source, distributed, fast and designed to scale to very large projects. Those were explicit design goals from the beginning.
  • Git is version-control software: it records the history of a project and makes it possible to compare, share and combine changes.
  • Git is the most dominant version-control system used in software development today.
  • Git was originally built to manage Linux development, but today it is used for: software,research code, data analysis,websites,documentation,books and much more.
  • Was Git originally designed to make version control easy for beginners?
    • No. It was designed to solve the collaboration problems of one of the world’s largest software projects (the development of Linux).
